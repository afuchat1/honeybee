# Hive of Hope Platform

PROJECT: HONEYBEE MINISTRIES OFFICIAL WEBSITE

Build a professional, clean, NGO-standard website for Honeybee Ministries (Uganda).

IMPORTANT:

This must NOT look like a startup SaaS website.

This must NOT use excessive cards, heavy shadows, or thick borders.

It must look like a credible, structured, child-support NGO website.

GENERAL DESIGN RULES

- Clean white background

- Primary color: Warm Honey Gold

- Secondary color: Deep Forest Green

- Accent: Soft earthy beige

- Minimal shadows

- Minimal borders

- Very limited use of cards

- Use spacing and typography instead of boxed layouts

- Professional NGO tone

- Soft but serious visual identity

- Mobile-first responsive design

- Perfect on mobile, tablet, and desktop

- No layout overlaps

- No visual clutter

NAVIGATION STRUCTURE

Top navigation must include:

Home

About Us

Programs

Impact

Daily Prayer

Governance

Contact

All inner pages MUST include breadcrumb navigation.

Example:

Home > Programs > Special Needs Support

Breadcrumb must be visible and properly structured for SEO.

-------------------------------------

Hero Section:

- Full-width banner (no boxed card)

- Tagline: Together we build a hive of hope

- Buttons:

  Join the Hive

Sections:

- About preview

  Special Needs Support

- Footer with contact details

- Special Needs Support

Each section must have:

- Brief description

No blog styling.

5) DAILY PRAYER PAGE (VERY IMPORTANT)

This section must be CMS-editable.

Admin must be able to:

Clean devotional layout (not blog format).

TECHNICAL REQUIREMENTS

- SEO optimized

- Clean semantic HTML structure

- Proper H1–H3 hierarchy

- Breadcrumb structured data

- Fast loading

- Secure contact form

- Accessibility compliant

- No unnecessary animations

- No visual bugs

- No broken routes

CMS REQUIRED FOR:

- Daily Prayer

- Gallery

- Impact updates

The final result must look like a serious, structured, child-support Christian NGO organization — trustworthy, stable, and professional.

No experimental designs.

No trendy SaaS UI.

No excessive card stacking.

No heavy shadows.

It must reflect stability, care, faith, and credibility.



PROJECT: HONEYBEE MINISTRIES – ADMIN DASHBOARD

Build a secure, professional Admin Dashboard with FULL CONTROL over the entire Honeybee Ministries website.

This dashboard must allow complete content management, file management, and data control.

PRIMARY ADMIN:
Email: amkaweesi@afuchat.com
Role: Super Admin (Full Permissions)

-------------------------------------

GENERAL REQUIREMENTS

- Secure authentication (email + password)
- Role-based access (future scalability)
- Session protection
- Secure password hashing
- Activity logs (track admin actions)
- Clean professional interface
- No heavy shadows
- Minimal cards
- Structured layout
- Desktop-first but fully responsive
- Sidebar navigation
- Top header with profile & logout

-------------------------------------

SIDEBAR MENU:

The system must function as a full content management system (CMS) for Honeybee Ministries.
